# Afonso Cordeiro

Master's in Artificial Intelligence and Data Science, focused on reinforcement learning and data engineering.

My master's thesis combined a hybrid LSTM and reinforcement learning system for statistical arbitrage pair trading, trained walk forward on S&P 500 data across the last 20 years. Alongside that, I built an end to end data lake pipeline for the global AI job market, ingesting data through a Pentaho ETL into a Supabase hosted PostgreSQL warehouse and visualizing it in Tableau, and a real time streaming pipeline processing live stock prices with Kafka and PySpark into InfluxDB and Grafana dashboards. I also explored generative modeling, comparing a VAE, a GAN, and diffusion based models on the ArtBench-10 dataset, and inverting target images into text prompts for a latent consistency model. I work extensively with AWS, using IAM for access control, Lambda functions, Step Functions workflows, and Bedrock for LLM based applications, applied both in the AWS-System-Design banking platform and in my AWS and Bedrock coursework.
